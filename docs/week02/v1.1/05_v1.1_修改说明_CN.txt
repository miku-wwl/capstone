1. P0-1 — 基线公平性
原 v1.0：OCC OFF 通过将按旧读余额计算的结果写回，可能人为制造 lost update；与 OCC ON 比较不公平。
修订：协议 §2–3 将 OFF 改为 PostgreSQL 当前行相对算术、业务谓词和 version increment（不按 version 匹配）；ON 在同一谓词/事务上加入 expected-version predicate，并对版本冲突整笔回滚重试。四组同事务、READ COMMITTED、schema、约束和更新顺序。旧值覆盖仅 W5 诊断反例。证据：PostgreSQL 18 Transaction Isolation / Explicit Locking 官方说明。
文件：02_实验协议_v1.1_CN.txt；中英提案 Methodology；PPT slides 6–8。

2. P0-2 — 文献与 gap
原 v1.0：19 项候选仅约 8 项进入核心学术书目；Histrio、DBOS、RIFL 等更接近的先例未被严谨定位，容易夸大“尚未研究”。
修订：补入 Plor、竞争度生成、Histrio、DBOS、RIFL 证据；记录书目映射、阅读范围、授权边界和筛选理由。gap 收敛为有限检索中的尚未发现：正确 PostgreSQL READ COMMITTED 转账 API 下，OCC×持久请求键 2×2 实证比较，并覆盖竞争、并发同键和 post-commit HTTP loss。声明是 bounded gap，不称 first-ever/全球不存在。
文件：01_新增文献与证据核查_CN.txt；01_研究空白修订说明_CN.txt；Proposal Literature Review/Gap；PPT slides 3–4,15–16。

3. P0-3 — RQ 与估计量
原 v1.0：RQ3 讨论异质故障条件的交互，但没有成对矩阵和统一估计式。
修订：RQ3 限定 W2/W4，预先匹配背景负载、seed、预分配重复率、retry budget 与窗口；给出区组内 I_W2、I_W4 和 ΔI；以加性 correctly-confirmed TPS 为主尺度，遇零吞吐不加伪常数；不足精度则 exploratory。完整区组为样本单位。
